СОСТОЯНИЕ ПРОЕКТА depthcsv — 2026-10-26 (v0.2)
=============================================

Назначение: запись без потерь diff depth 100 мс + aggTrade + REST-снимков Binance USDⓈ-M Futures для бэктеста (2–4 недели).
По умолчанию BTCUSDT, ETHUSDT. Telegram удалён, выгрузка через rclone в gdrive:depthcsv/.

Почему не bklog: bklog хранит цены/объёмы целыми по pricePrecision (не raw), в aggTrade теряет E/f/l, recv в мкс,
bkcat не умеет JSONL/CSV — условие «без потерь + raw + выгрузка» не выполнялось. bklog не трогался.

Файлы
-----
src/main.rs              рекордер: 2 WS (/public depth, /market aggTrade), снимки, детектор GAP, запись gzip, .done, stats
src/verify.rs            подкоманда verify: сборка стакана, сверка top-50 на снимках, GAP, покрытие, по дням
depthcsv.service         основной сервис (Restart=always, журнал)
depthcsv-upload.sh/.service/.timer   выгрузка rclone move каждые 10 мин, flock, WARN при <5 ГБ
depthcsv.env.example     конфиг без секретов

Тесты (cargo test): разбор заголовков/время, детектор цепочки (норма/дубль/пропуск/реконнект/aggTrade),
переполнение очереди -> GAP queue_overflow + запрос снимка; verify: синхронизация+проверка, пропущенное сообщение
(необъяснённый разрыв), разрыв с маркером, дубль, реконнект/рестарт, несовпадение, маркер без разрыва, числа.
